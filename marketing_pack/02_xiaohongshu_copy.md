## 正文文案

最近很多用 Claude Code / Cline / Cursor 的朋友在问国内各家的 Coding Plan 包月套餐怎么选，直接把对着官方文档核验完的硬规则发出来避坑（核验日 2026-11-13）：

1️⃣ **「提问次数」不等于「模型调用次数」**
Agent 修一个 Bug 往往自动读文件+跑测试循环 10～25 轮。如果日均冲到 **5,000 次模型调用**，30 天就是 **15 万次**——而百炼、腾讯云、火山方舟 Pro 档月上限都是 **9 万次（90,000 次）**，每 5 小时还限 **6,000 次**！

2️⃣ **分清「首月活动价」和「次月续费原价」**
- 阿里云百炼：Lite 已停止新购；Pro 新客首月特惠 **¥39.90**，次月续费原价 **¥200/月**（月上限 9 万次）。
- 腾讯云 LKEAP：Lite 原价 **¥40/月**（5h 限 1,200 次 / 月限 1.8 万次）；Pro 原价 **¥200/月**（5h 限 6,000 次 / 月限 9 万次）。
如果同模型开启 50% 缓存命中后按量月账单不到 ¥100，次月按 ¥200 原价续费反而更贵！

3️⃣ **千万别把套餐 Key 填进普通按量端点！**
- 百炼 Coding Plan + Claude Code：`https://coding.dashscope.aliyuncs.com/apps/anthropic`
- 腾讯 Coding Plan + Claude Code：`https://api.lkeap.cloud.tencent.com/coding/anthropic`
填成通用按量 `/v1` 地址会继续扣账户按量费用。另外非交互式后端/批处理严禁使用个人编程套餐。
